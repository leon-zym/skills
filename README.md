# skills

My personal collection of [Agent Skills](https://agentskills.io) — reusable instruction sets for AI coding agents.

[![skills.sh](https://img.shields.io/badge/skills.sh-leon--zym%2Fskills-blue)](https://skills.sh/leon-zym/skills)

## Install

```bash
# Everything in this repository
npx skills add leon-zym/skills

# A single skill
npx skills add leon-zym/skills --skill coordinate-work
```

`-g` installs globally instead of into the current project, `-a <agent>` targets a specific agent, and `--list` shows what is available without installing anything.

Prefer not to use the CLI? Download the bundled zip from [Releases](https://github.com/leon-zym/skills/releases/latest) and unzip it into your agent's skills directory.
